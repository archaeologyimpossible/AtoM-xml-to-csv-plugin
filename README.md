# readme

- for use with AtoM EAD 2002 xml export.
- install the plugin
- in chrome, select or open the xml export.
- hit the plugin
- select whether you want the inventory or digital identifiers; you really want both, for data tracking

## Installation

Open chrome://extensions/.

Find Archive XML to CSV Exporter and click the Refresh / Reload icon (⟳).

Go to a page in the archive, [eg like this](https://magdalene.maxarchiveservices.co.uk/index.php/to-ruth-turner-27th-may-1914) and then select the EAD 2002 xml export. In chrome, this will open the xml file in a new tab.

In that tab, open the extension and click Load & Preview, then export.

Result: xml reshaped into csv with the data you want.
